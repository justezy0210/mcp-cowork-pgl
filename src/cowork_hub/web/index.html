연결 준비

새 토큰 만들기

사용할 곳을 이름으로 적어 두면 나중에 구분하기 쉽습니다.

토큰은 발급 직후에만 받을 수 있습니다. 기존 토큰은 계속 유지됩니다.

발급 완료

토큰 파일을 저장하세요

에 사용할 개인 토큰이 준비됐습니다.

다운로드한 파일을 본인 컨테이너의 토큰 경로에 두고 권한을 600으로 설정하세요. 이 화면을 닫으면 다시 다운로드할 수 없습니다.

내 연결 관리

발급한 토큰

아직 발급한 토큰이 없습니다. 위에서 첫 토큰을 만들어 보세요.

    이 화면에서 발급한 토큰을 관리합니다. 관리자가 처음 전달한 기존 토큰은 이 목록에 표시되지 않습니다.

    기존 작업을 취소하거나 예약을 반환하는 동작은 아닙니다.
